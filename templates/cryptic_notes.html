Cryptic Notes

Everything for /cnmatch: the maps, the codex (anomalies and classics), and the result texts. Anomalies and classics only appear on the maps that are ticked for them.

How a run works
  1. The character (or the whole group) runs into one random anomaly that can appear on the map.
  2. Each character can be killed by that anomaly. The higher its danger, the likelier: {% for level, chance in kill_chance.items() %}danger {{ level }} = {{ chance }}%{% if not loop.last %} · {% endif %}{% endfor %}.
  3. Otherwise each character can still die another way (quota not met, a fall, ...): the map's chance below. From the 4th run within an hour the character is exhausted and this chance goes up.
  4. Survivors find 1–9 classics (5–6 is most common) from the map's classics. The tier decides how often: {% for key, t in tiers.items() %}{{ t.emoji|emoji }} {{ t.label }} {{ t.weight }}%{% if not loop.last %} · {% endif %}{% endfor %}. Within a tier, a higher "how common" value comes up more often.
  5. The dead keep nothing and wake up in the Manor's infirmary. Survivors get a small Clues bonus and can /sell their classics.

These rules (percentages, bonus, exhaustion) are set in config.py under "CRYPTIC NOTES".

Result Texts

For every run the bot picks a random text for the result type, from the texts for that map or for both maps. Placeholders: {character} {map} {count} (number of classics), {anomaly} (the killer, or the deadliest anomaly present) and {anomalies} (all anomalies of the match, e.g. "Wraith and Shade"). The infirmary line is added automatically to deaths.
